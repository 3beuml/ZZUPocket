## 不在本仓库里的东西（以及为什么）

- **探测脚本与原始抓包**（登录态、接口原始响应、页面 dump）：**不入库**。它们包含登录令牌与个人数据，
  历史产物留在作者本机 `_research/`。需要重现某个结论时，按上面几份文档里的路径与参数自行复现。
- **本机构建/装机的环境笔记**：含设备序列号，不入库。通用部分见根目录 `README.md` 的「构建」一节。
