- **CAS（`cas.s.zzu.edu.cn`）**：用户的统一登录，登录后拿到 `userToken`（= `idToken`），**有效期约 1 个月**。它是大多数校内系统的通行证，但**每个系统取用方式不同**。
- **教务 EAS（`jwxt.zzu.edu.cn`）**：路径前缀是 `eams-door` 与 `eams-micro-server/api/v1`；请求头是 `Authorization: <userToken>`——**裸值，不加 `Bearer`**。
- **一卡通（`ecard.v.zzu.edu.cn/server/...`）**：用自己的 `accessToken`，**约 40 分钟过期**，要独立刷新。
- **校园卡余额（`info.s.zzu.edu.cn/portal-api/v1/thrid-adapter/get-person-info-card-list`）**：请求头 `X-Id-Token: <CAS userToken>`；余额取 `data[1].amount`（**取 `data[0]` 会得到 0**）。
- **图书馆（`order.lib.zzu.edu.cn`）**：Vue3 + Ant Design Vue 的 H5 单页应用；有它自己的 `POST /v4/login/login`（`isCrypto:true`），会话是 **cookie**（未登录时 `/v4/member/seat` 返回 `{"code":10001,"message":"您尚未登录"}`）。App 里实际走通的路子是**用 CAS 票据自动登录**：`/h5/` → `#/` → `#/login` → `#/cas/?cas=<ticket>` → `#/mo/home`。
- **图书馆域名只能走明文 HTTP:80**（校外 443 被校园网边界拒绝），所以 `network_security_config` 只给这一个域名放行 cleartext。

**Why:** 这几个系统的鉴权方式互相不通用，猜错就是 401/空数据，白折腾很久。
**How to apply:** 接新接口前先确认它属于上面哪一类、要哪个头；会话过期时间不同（40 分钟 vs 1 个月）决定要不要做刷新。
