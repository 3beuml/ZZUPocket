# 冲突课表显示

同一教学周、同一天的多门课占用相同节次时，周网格默认显示「课程冲突（甲…/乙…）」。
占位沿用课程块的尺寸、圆角与密度，使用主题警示底色、深警示色文字与 2dp 实线边框，
在多彩/单色模式下都与普通课程区分。「课程冲突」使用正常课程名字号并加粗，不随名称长度缩小。
只有课程名做截断；完整名称、教师、地点与各自起止节次均在详情顶部显示。
选定显示课程后恢复该课程的普通配色，保留小「冲」标记与原有冲突入口。

详情顶部使用同一套主题警示色，标题为 24sp 粗体并带警示图标；课程名、当前显示和分组标题
增强字重，保存按钮使用主题主按钮样式。字体仍继承应用的系统字体，操作与本地保存逻辑不变。

## 使用

1. 点击冲突占位，原课程详情顶部会增加「冲突详情」。点各门课旁的「查看详情」，
   下方切换为这门课原有的详情内容。
2. 保持默认时无需操作。点击「更改显示」，可继续保留占位，或选择显示其中一门。
3. 选择适用的教学周：默认仅本周，也可选全部相同冲突周、单周、双周，或逐周多选。
4. 保存后，仅所选周改变。块上的小「冲」标记保留入口；再次点击可以修改选择，
   或按所选周恢复「课程冲突占位」。

首页当天时间轴沿用同一套逐周选择：未处理的冲突合并为一条「课程冲突」，
用 16sp 粗体、警示图标、主题警示浅底和细边框提示，并列出课程名。
该提示与红色「现在」时间标记在形状、字号和字重上区分；时间标记保留原有样式。
已选定显示课程时按普通课程显示，不再重复警示；从课表返回和重新进入应用时都会读取本地选择。
部分重叠只标记重叠区间，选择后相邻的同一课程片段在时间轴中合并；顶部下一节/正在上课提示
及明天概览使用同一份显示结果。点击时间轴仍沿用原有的进入课表操作。

原始课程、小组件日程和专注记录均保留，被选为暂不显示的课仍可从冲突详情查看。
重新同步或重启应用后选择继续生效。

## 区间与本地保存

- 甲为 1–4 节、乙为 3–6 节时，网格显示：甲 1–2 / 冲突 3–4 / 乙 5–6。
  相邻且不共用节次的课程不算冲突，不同学期、周次、星期分开计算。
- 冲突标识由学期、星期、重叠节次与全部参与课程的稳定时段标识生成，
  不包含周号、记录顺序、课程名或教室等可编辑文本。
- 选择复用 `display_overrides` 表的 `kind = "conflict"`：`courseCode` 存冲突标识，
  `value` 存选中课程的时段标识，`weeks` 存一个周号。一周一条，改部分周不影响其他周。
  名称/地点覆盖仍按原逻辑工作，不需要数据库迁移。
- 研究生系统共用合成学期编号，另外使用接口的实际学期值隔离选择，并随课表缓存保存。
  旧版研究生缓存需先刷新一次，确认学期后再提供显示选择。
- 同步只更新课程和上课记录，不改显示覆盖。冲突成员或时段改变后，旧选择不再匹配，
  新冲突恢复占位，避免无提示地隐藏新加入的课程。
- 同课程、同时间的理论与实验记录使用不同主键；缓存版本提升一次，以重新拉取旧版可能覆盖的记录。
- 清除课表缓存时，冲突选择按现有显示覆盖的生命周期一起清除。

## 验证

- `ScheduleConflictsTest`：完整/部分重叠、包含、链式重叠、多门课、跨周/跨学期、
  重新同步后稳定匹配、变更后回退，以及逐节核对随机时段的完整性。
  包含本科周二 9–10 节「工程制图 / 探索人体的奥秘」的报告案例（周次等其他字段为模拟值）。
- `ConflictDisplayPersistenceTest`：真实 Room 保存 → 重新同步 → 关闭重开数据库，
  验证按周选择保留、部分周恢复不影响其他周和课程名覆盖，以及首页 ViewModel
  首次加载、保存后返回、关闭重开数据库后的显示结果和研究生学期隔离。
- `ConflictDisplayUiTest`：三档密度的占位截图、点击取得全部冲突课程、选课与周次、
  空周次禁止保存，以及单色/无边框、强制深色和选定显示后保留冲突入口。
  截图使用暖色主题，输出到测试设备的应用外部文件目录 `conflict-test-screenshots`。
- `TodayCourseDisplayTest`：首页完整/部分重叠、逐周选择、新成员回退、选定后的片段合并、
  缺少周网格信息的补课和顶部提示文案。
- `TodayConflictUiTest`：真实 Room、首页 ViewModel 与 `TodayScreen`，验证首次进入、
  课表选择后返回、未处理冲突与红色「现在」同时显示，以及深色主题和 1.3 倍字体。
- 真实教务账号的最终验收需由持有账号的用户完成；测试数据不含身份信息或登录凭据。
